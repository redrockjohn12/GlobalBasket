GLOBAL BASKET ESWATINI - WOW VERSION

TERMUX INSTALL
1. Download the ZIP to your phone.
2. In Termux:
cd ~
rm -rf ~/GlobalBasketEswatini
mkdir ~/GlobalBasketEswatini
unzip ~/storage/downloads/GlobalBasketEswatini-WOW.zip -d ~/GlobalBasketEswatini
cd ~/GlobalBasketEswatini
python -m http.server 8080

3. Open http://127.0.0.1:8080

PUBLIC / GOOGLE
Before publishing, replace https://YOUR-DOMAIN.example/ in index.html, robots.txt and sitemap.xml with the real public HTTPS domain. Deploy the folder to a public host, then add the site to Google Search Console and submit /sitemap.xml.

NOTE
WhatsApp cannot be used by a normal static webpage to automatically attach a customer's local screenshot. The site therefore instructs customers to take a screenshot and attach it in WhatsApp themselves, while the WhatsApp buttons pre-fill the message.
